# Introduction to Rust: Build a Command-Line Notes App

A from-scratch beginner project for people who have never written Rust. You learn the language the way it is actually used — by building one real program end to end — a command-line notes app that adds, lists, searches, and saves notes. Starting from what Cargo even is, you meet variables and types, write functions, branch with control flow, then dive into Rust's signature ideas — ownership and borrowing — from first principles. You model data with structs and enums, match on patterns exhaustively, store many notes in a Vec, parse command-line arguments, handle errors with Result instead of crashing, save and load notes from a file, and finally split the program into modules. Every concept is taught with the why behind it, so you finish understanding not just Rust's syntax but why its compiler keeps your programs correct.

## Stack
- Rust
- Cargo
- Ownership
- Pattern Matching
- Result
